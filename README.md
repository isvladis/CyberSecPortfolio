# Cyber Matrix Portfolio

Portfolio interactivo de ciberseguridad para `DYSLABS_SEC`, construido con Next.js App Router, React, Tailwind CSS y Framer Motion.

## Características

- Hero estilo Matrix con terminal interactiva.
- Simulación de protocolo de alerta y recuperación tipo ransomware.
- Tarjetas de proyectos de hardening, VPN, Pi-hole y portfolio.
- Monitor visual de tráfico de red.
- Feed de noticias CyberSec servido desde una API interna cacheada.

## Desarrollo

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) para ver la aplicación.

## Verificación

```bash
npm run lint
npm run build
```
